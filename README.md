# Git·GitHub 인터랙티브 튜토리얼 🎮

화면의 안내를 따라 직접 Git 명령어를 입력하며 배우는 실습형 튜토리얼입니다.
게임처럼 7개의 단계(Step)를 하나씩 깨면서 진행해요.

```text
Step 1  준비하기 & 저장소 만들기
Step 2  첫 커밋 만들기
Step 3  변경을 기록하고 이력 보기
Step 4  브랜치 만들고 병합하기
Step 5  GitHub에 올리기
Step 6  Pull Request 보내기
Step 7  충돌(Conflict) 해결하기
```

## 시작하기 전에 (5분)

### 1. Git 설치

- <https://git-scm.com/downloads> 에서 다운로드해 설치하세요.
- 설치 중 나오는 선택지는 **전부 기본값 그대로** Next를 눌러도 됩니다.
- 설치되어 있는지 모르겠다면? 그냥 아래 "시작하기"를 해 보세요 —
  Git이 없으면 다운로드 페이지를 자동으로 열어 줍니다.

### 2. GitHub 계정 만들기

- <https://github.com> 에서 무료 계정을 만들어 두세요. (Step 5부터 사용합니다)

## 시작하기 🚀

**이 폴더의 `시작하기.bat` 파일을 더블클릭하세요.** 끝!

터미널 창이 자동으로 열리면서 튜토리얼 화면이 시작됩니다.
화면은 두 부분으로 나뉘어요 — **위쪽은 안내(고정), 아래쪽은 터미널**:

```text
 Git·GitHub 튜토리얼   챕터 [■□□□□□□] 2/7
──────────────────────────────────────────────────
 챕터 2/7 : 첫 커밋 만들기 (add & commit)
──────────────────────────────────────────────────
 기록의 3단계: 파일 수정 → git add → git commit

  ✔ edit 입력 → 'TODO-이름' 줄을 내 이름으로 바꾸고 저장 → Enter
  ▶ git status                    ← 수정된 파일이 빨간색으로!
  · git add .
  · git status
  · git commit -m "프로필에 이름 작성"

 ▶ 지금 할 일:  git status
   git status = 지금 저장소의 상태를 보여주는 명령이에요.
──── 터미널 ── ▶ 표시된 명령을 입력하세요 ── hint 힌트 · edit 파일 열기 ────
명령> _                                          ← 아래: 터미널
```

**진행 방식**: 전체 과정은 7개 챕터, 46개의 작은 단계로 되어 있어요.
`▶` 표시된 명령을 그대로 입력하면 실행되고, 결과가 올바르면 **자동으로 다음
단계**로 넘어갑니다. 틀린 명령을 입력하면 실행되지 않고 무엇을 입력해야 하는지
알려주니, 실수해도 망가질 걱정이 없어요!

### 화면 사용법

| 입력 | 하는 일 |
|---|---|
| `▶` 표시된 git 명령 | 실행 → 검증 → 통과하면 자동으로 다음 단계! |
| `Enter` (빈 입력) | 파일 수정/브라우저 작업 단계에서 "다 했어요" 확인 |
| `git status`, `git log`, `git diff` | 구경용 명령 — 언제든 입력해도 OK (진행과 무관) |
| `hint` | 지금 단계의 힌트 |
| `edit` | 실습 파일(profile.md)을 메모장으로 열기 |
| `progress` | 지금까지 얼마나 왔는지 보기 |
| `quit` | 종료 (진행 상황은 저장돼요 — 언제든 이어서!) |

### 더블클릭으로 실행이 안 될 때 / Mac·Linux에서

터미널(Windows는 Git Bash)을 이 폴더에서 열고 직접 실행하세요:

```bash
./tutorial.sh
```

(Windows: 폴더 빈 곳에서 마우스 오른쪽 클릭 → "Open Git Bash here".
Windows 11은 "더 많은 옵션 표시"를 먼저 눌러야 보일 수 있어요.)
